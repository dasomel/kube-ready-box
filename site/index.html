kube-ready-box

Vagrant box catalogs. The .box files are GitHub Release assets; each catalog carries the URL and sha256 checksum.

vagrant box add https://dasomel.github.io/kube-ready-box/boxes/<name>.json

Pick a provider or architecture explicitly when needed:

vagrant box add --provider vmware_desktop --architecture arm64 \
  https://dasomel.github.io/kube-ready-box/boxes/<name>.json

Catalogs are the boxes/*.json files in this site. Source and releases: github.com/dasomel/kube-ready-box.
